# Subs

Static GitHub Pages package for the subtitle evaluation page.

## Publish with GitHub Pages

1. Open the repository on GitHub.
2. Go to `Settings` -> `Pages`.
3. Under `Build and deployment`, choose `Deploy from a branch`.
4. Select `main` and `/ (root)`, then save.
5. Share the published URL with raters.

The default project URL will be:

```text
https://haibojin001.github.io/Subs/
```

## Collect Ratings

Ask each rater to:

1. Open the GitHub Pages URL.
2. Enter a unique rater ID.
3. Complete all ratings.
4. Click the JSON or CSV export button.
5. Send the downloaded `ratings_<ID>.json` or `ratings_<ID>.csv` file back to you.

Progress is stored in each rater's browser with `localStorage`, so it stays on that device/browser until they clear it.
